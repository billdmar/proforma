# WORKBOOK_SPEC.md — the live-formula merger model (frozen at W0, ORCH-owned)

The workbook is generated by `src/workbook/writer.py` (openpyxl) from the
`MergerModelBundle` — **the single source of truth**. Every computed cell is a
**live Excel formula** referencing other cells; the Python engine computes the
same numbers independently, and the differential verifier
(`src/verify/recalc.py`, the `formulas` library) recalculates the workbook and
matches every cell in `build_verifier_cell_map` to the engine **to the cent**
(tol = 0.01). No number is ever hand-typed into a formula cell.

## Cell conventions (banker standard; enforced by `src/verify/audit.py`)
- **Blue font** = hard input. Blue cells appear **only** on the Assumptions tab
  (and Cover metadata). Every blue cell traces to `docs/ASSUMPTIONS.md`.
- **Black font, formula** = computed. `styles.formula_cell` raises `ValueError`
  unless the string starts with `=` — the enforcement point against hardcodes.
- **Black font, value** = a reported historical or an engine-output anchor
  (labeled), never a hand-typed projection.
- Values stored in raw USD; display scaling is a number format, not a division
  baked into a formula. Number formats: currency `#,##0;(#,##0)`, percent
  `0.0%`, per-share `0.00`, multiple `0.0x`, shares, year.
- Consistent signs: outflows negative; interest expense positive and subtracted
  explicitly. Named ranges for every headline output.
- Cross-tab references use the `self._anchors` dict (reused from thesis) so no
  coordinate is hardcoded twice. Deterministic save (`_save_pinned`) →
  byte-identical rebuilds.

## Tab order (13 sheets)
1. **Cover** — deal one-liner, parties, announce/close dates, headline
   consideration, Yr1–3 accretion/(dilution) under both synergy cases, links.
2. **Assumptions** — the ONLY blue-input tab. Sections: standalone drivers
   (acquirer + target), deal terms (disclosed, provenance-noted), our deal
   assumptions (financing, fees, PPA choices), synergy cases (management vs ours).
3. **Acquirer** — standalone: XBRL-tied historicals + driver-based projection.
4. **Target** — standalone, same structure.
5. **Deal & S&U** — consideration build (cash + stock legs, premium), sources &
   uses (must balance — invariant).
6. **PPA** — equity purchase price → write off existing goodwill → identifiable
   net assets → step-ups → deferred-tax liability → **goodwill (the plug)**.
7. **Pro Forma IS** — combined income statement per projected year: +target,
   −incremental interest, −foregone interest income, −incremental D&A (after
   tax), +synergies (after tax), → pro forma net income → pro forma EPS.
8. **Pro Forma BS** — combined balance sheet (must balance every period).
9. **Accretion/Dilution** — the EPS bridge and A/D % by year, both synergy cases.
10. **Contribution** — each party's revenue/EBITDA/NI contribution vs. pro forma
    ownership (existing shares vs. new shares issued); exchange-ratio analysis.
11. **Sensitivities** — premium × synergies grid, consideration-mix grid,
    breakeven synergies. Monotone by construction (gate: DoD #5).
12. **Precedents** — curated premiums-paid / multiples table, every row cited.
13. **Fairness Comparison** — advisors' disclosed implied ranges vs. our
    reproduction from their disclosed assumptions; overlap per method.

## Named ranges (headline outputs)
`DealValue`, `EquityPurchasePrice`, `CashPerShare`, `ExchangeRatio`,
`ImpliedPremium`, `Goodwill`, `NewDebt`, `NewSharesIssued`, `ProFormaEPS_Y1`,
`Accretion_Y1`, `Accretion_Y2`, `Accretion_Y3`, `BreakevenSynergies`,
`AcquirerOwnership`, `TargetOwnership`.

## `build_verifier_cell_map` (differential coverage)
Co-located with the writer (thesis pattern). Maps `(sheet, coord) -> engine
value` for every formula cell that must reproduce an engine output: the S&U
totals, goodwill, each projected-year pro forma net income / EPS / accretion
cell, contribution percentages, and the sensitivity-grid centre cell. The
verifier flags any cell where `|workbook − engine| > 0.01` or the cell is
missing. The README reports the count of cells verified.
